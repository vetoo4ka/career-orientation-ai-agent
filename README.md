# Личный ИИ-агент
Проект из School 21, в рамках которого я создала ИИ-агента, который:

Поддерживает в выборе направления обучения в «Школе 21»;
Присылает регулярный дайджест новых материалов по выбранному профилю;
Помогает с анализом рынка вакансий и отслеживанием новых требований и компетенций для успешного трудоустройства в будущем;
Подбирает актуальные материалы для выполнения учебных проектов.

# Task 1. Знакомство с инструментами
В рамках первого задания, я изучила, настроила и подключила необходимые инструменты для дальнейшей работы по созданию ИИ-агента:
1. n8n
2. Cloud.ru
3. работа с GigaChat API
