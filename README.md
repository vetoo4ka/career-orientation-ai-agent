# Личный ИИ-агент карьерного консультирования в IT

Проактивный ИИ-агент, помогающий новичкам в IT выбрать специализацию и составить план развития. Проект создан с помощью **n8n**, **Cloud.ru**, **GigaChat API** в рамках обучения в «Школе 21».

## О проекте

Агент автоматизирует ключевые задачи при выборе специализации в IT:

**Выбор специализации**  
Telegram-бот анализирует твой опыт, интересы и цели, чтобы порекомендовать подходящее направление (например, QA, разработка или аналитика) и конкретный стек технологий.

**Дайджест новостей**  
Агент парсит профильные Telegram-каналы, суммаризирует посты через LLM и присылает ежедневный дайджест в твой личный тг-канал.

**Анализ рынка вакансий**  
Раз в неделю агент собирает свежие вакансии с hh.ru по выбранному направлению, выделяет топ-15 ключевых навыков и показывает тренды рынка.

**Персональный ментор**  
Бот составляет учебный план по нужной теме, а затем присылает ежедневные посты с разбором каждого понятия, отслеживая прогресс.

### Цель проекта

Цель проекта — не просто разово выполнить проект, а создать ИИ-агента, которого можно развивать и адаптировать под реальные карьерные задачи. Ключевой элемент проекта — тщательно спроектированные системные промпты, превращающие LLM из простого ассистента в проактивного агента.

## Технологический стек

*   **Платформа:** n8n
*   **LLM:** GigaChat 2 (через API Cloud.ru)
*   **Мониторинг:** Telegram Bot API
